## 标准版（推荐）

面试官好，我来介绍一下我的苍穹外卖项目。

这是一个基于 **Spring Boot + MyBatis + Redis + WebSocket** 的外卖点餐系统，包含**管理端和微信小程序用户端**双端功能，覆盖了从用户浏览菜品、下单支付、到商家接单配送、再到数据统计运营的完整业务链路。

技术架构上我采用了 **Maven多模块设计**，拆分为 common公共模块、pojo对象模块、server主业务模块三层，职责清晰避免循环依赖。

在**安全认证**这块，我实现了 JWT令牌配合自定义拦截器的双端认证方案——管理端和用户端使用独立的密钥和Token名称实现安全隔离。然后通过 ThreadLocal 做请求级上下文传递，业务层直接获取当前用户ID，避免了层层传参的啰嗦。

**数据层**方面，我用 Redis 缓存了店铺营业状态这类读多写少的数据。报表功能用 Apache POI 的模板填充模式导出 Excel，文件上传对接了阿里云 OSS。数据库访问用 MyBatis 配合 PageHelper 分页插件，XML 和注解按复杂度灵活选择。

**实时通信**是一个亮点。我通过 WebSocket 实现了两类消息推送——用户支付成功后的**来单提醒**和用户催单的**催单提醒**，服务端主动推送给所有在线管理员，比轮询方案实时性高很多。同时用 Spring Task 定时任务做订单超时自动取消和配送超时自动完成的兜底处理。

**支付集成**方面完成了微信小程序登录的完整流程——code 换 openid、自动注册、签发JWT；以及微信支付回调的 AES 解密处理，支付成功后串联订单状态变更和 WebSocket 推送整条链路。

另外还做了 AOP 加反射的公共字段自动填充、全局异常处理器统一捕获十几种业务异常、DTO/VO/Entity 三层参数隔离这些工程化实践。

以上就是我的项目介绍。

## 精简版（如果面试官只给1分钟）

我做一个基于 Spring Boot 的苍穹外卖系统，管理端加微信小程序双端。

核心亮点有这么几个：

**一是安全认证体系**，JWT 双拦截器加 ThreadLocal 上下文传递，管理端用户端密钥隔离。

**二是 WebSocket 实时通信**，做了来单提醒和催单提醒两类推送，替代传统轮询方案。

**三是微信支付全流程集成**，包括小程序登录、AES 回调解密、支付成功后状态流转加 WebSocket 通知的完整链路。

**四是工程化实践**，AOP 自动填充公共字段、全局异常统一处理、Redis 缓存、POI 报表导出、OSS 文件上传、Maven 多模块分层。

技术上覆盖了 Spring 全家桶、MyBatis、Redis、WebSocket、微信支付这些主流组件，整体难度对标中型互联网公司的后端开发要求。

### 面试官可能追问的方向（提前准备）

说了这段之后，面试官大概率会顺着追问：
- "ThreadLocal 内存泄漏怎么防？" → afterCompletion 里 remove()
- "WebSocket 断了怎么办？" → 三级改进方案
- "缓存一致性怎么保证？" → 先更新DB再删缓存
- "定时任务有什么缺点？" → 精度有限、单机限制、无可视化

这些你的 Q&A 文档里都有，放心回答。
