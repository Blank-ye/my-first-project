
# 苍穹外卖项目分布式改造方案

## 一、项目概述

### 1.1 当前架构
- **单体架构**：所有功能模块耦合在一个 sky-server 应用中
- **技术栈**：Spring Boot 3.5.6 + MySQL + Redis + MyBatis + WebSocket
- **数据库**：包含11张核心表

### 1.2 改造目标
- 将单体应用拆分为多个微服务
- 保持前端代码不变（通过网关统一路由）
- 提高系统可扩展性、可维护性
- 实现服务独立部署、独立扩展

---

## 二、微服务拆分方案

### 2.1 服务划分原则
- 按业务领域划分（DDD思想）
- 高内聚、低耦合
- 数据库按服务垂直拆分

### 2.2 微服务列表

| 服务名称 | 服务端口 | 数据库 | 负责业务 |
|---------|---------|--------|---------|
| sky-gateway | 8080 | - | 网关服务、统一路由、鉴权 |
| sky-user-service | 8081 | sky_user | 用户、地址簿 |
| sky-order-service | 8082 | sky_order | 订单、购物车、支付、报表统计、工作台 |
| sky-product-service | 8083 | sky_product | 分类、菜品、套餐 |
| sky-employee-service | 8084 | sky_employee | 员工管理 |

### 2.3 数据库表分配

#### sky_employee 数据库
- employee（员工表）

#### sky_product 数据库
- category（分类表）
- dish（菜品表）
- dish_flavor（菜品口味表）
- setmeal（套餐表）
- setmeal_dish（套餐菜品关系表）

#### sky_user 数据库
- user（用户表）
- address_book（地址表）

#### sky_order 数据库
- shopping_cart（购物车表）
- orders（订单表）
- order_detail（订单明细表）

## 三、技术选型

### 3.1 核心技术栈
| 组件 | 选型 | 版本 | 说明 |
|-----|------|-----|-----|
| 注册中心 | Nacos | 2.2.x | 服务注册与发现 |
| 配置中心 | Nacos | 2.2.x | 统一配置管理 |
| 服务网关 | Spring Cloud Gateway | 4.x | 统一入口、路由转发 |
| 服务调用 | OpenFeign | 4.x | 服务间同步调用 |
| 服务熔断降级 | Alibaba Sentinel | 1.8.6 | 熔断降级、流量控制 |
| 分布式事务 | Seata | 1.7.x | 保证数据一致性 |
| 消息队列 | RabbitMQ | 3.12.x | 异步解耦、订单超时 |
| 分布式缓存 | Redis | 7.x | 缓存共享 |
| 分布式锁 | Redisson | 3.24.x | 防止并发问题 |

#### 5.1.2 创建Feign客户端接口

在 `sky-api/src/main/java/com/sky/api/` 下创建所有Feign客户端接口：

**1. ProductClient.java（商品服务）**

```java
package com.sky.api;

import com.sky.api.fallback.ProductClientFallback;
import com.sky.entity.Category;
import com.sky.entity.Dish;
import com.sky.entity.Setmeal;
import com.sky.result.Result;
import org.springframework.cloud.openfeign.FeignClient;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import java.util.List;

@FeignClient(name = "sky-product-service", 
             path = "/api/product",
             fallback = ProductClientFallback.class)  // 指定降级实现类
public interface ProductClient {

    @GetMapping("/category/{id}")
    Result&lt;Category&gt; getCategoryById(@PathVariable Long id);

    @GetMapping("/dish/{id}")
    Result&lt;Dish&gt; getDishById(@PathVariable Long id);

    @GetMapping("/setmeal/{id}")
    Result&lt;Setmeal&gt; getSetmealById(@PathVariable Long id);

    @GetMapping("/dish/list/{categoryId}")
    Result&lt;List&lt;Dish&gt;&gt; listDishByCategoryId(@PathVariable Long categoryId);
}
```

```java
package com.sky.api.fallback;

import com.sky.api.ProductClient;
import com.sky.entity.Category;

import com.sky.result.Result;

@Slf4j
```

#### 5.2.2 创建配置文件

`sky-gateway/src/main/resources/application.yml`：

```yaml
server:
  port: 8080

spring:
  application:
    name: sky-gateway
  cloud:
    nacos:
      discovery:
        server-addr: localhost:8848
      config:
        server-addr: localhost:8848
        file-extension: yml
    gateway:
      discovery:
        locator:
          enabled: true
      routes:
        # 员工管理服务路由
        - id: sky-employee-service
          uri: lb://sky-employee-service
          predicates:
            - Path=/admin/employee/**,/admin/common/**
          filters:
            - StripPrefix=0
        
        # 商品服务路由
        - id: sky-product-service
          uri: lb://sky-product-service
          predicates:
            - Path=/admin/category/**,/admin/dish/**,/admin/setmeal/**,/admin/shop/**,/user/category/**,/user/dish/**,/user/setmeal/**,/user/shop/**
          filters:
            - StripPrefix=0
        
        # 用户服务路由
        - id: sky-user-service
          uri: lb://sky-user-service
          predicates:
            - Path=/user/user/**,/user/addressBook/**
          filters:
            - StripPrefix=0
        
        # 订单服务路由（包含报表统计、工作台）

          predicates:
            - Path=/user/shoppingCart/**,/user/order/**,/admin/order/**,/notify/**,/admin/report/**,/admin/workspace/**

            - StripPrefix=0
```

```java
package com.sky.controller.api;

import io.swagger.v3.oas.annotations.tags.Tag;
import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.*;

import java.util.List;

@RequestMapping("/api/product")
@Slf4j
@Tag(name = "商品内部接口")
public class ProductApiController {

    @Autowired
    private CategoryService categoryService;

    @Autowired
    private DishService dishService;

    @Autowired
    private SetmealService setmealService;

    @GetMapping("/category/{id}")
    @Operation(summary = "根据ID查询分类")

    @GetMapping("/dish/{id}")

    public Result&lt;Dish&gt; getDishById(@PathVariable Long id) {
        Dish dish = dishService.getById(id);
        return Result.success(dish);
    }

    @GetMapping("/setmeal/{id}")
    @Operation(summary = "根据ID查询套餐")
    public Result&lt;Setmeal&gt; getSetmealById(@PathVariable Long id) {
        Setmeal setmeal = setmealService.getById(id);
        return Result.success(setmeal);
    }

    @GetMapping("/dish/list/{categoryId}")
    @Operation(summary = "根据分类ID查询菜品列表")
    public Result&lt;List&lt;Dish&gt;&gt; listDishByCategoryId(@PathVariable Long categoryId) {
        List&lt;Dish&gt; list = dishService.listByCategoryId(categoryId);
        return Result.success(list);
    }
}
```

### 6.3 用户信息传递机制（网关+拦截器+Feign）

在微服务架构中，用户信息需要在网关、微服务之间传递。本方案采用以下设计：

**整体流程**：
1. **网关层**：使用 GlobalFilter 进行身份验证，验证通过后将用户信息存入请求头
2. **微服务层**：通过拦截器从请求头获取用户信息，保存到 ThreadLocal
3. **服务间调用**：通过 Feign RequestInterceptor 将用户信息传递给下游服务

#### 6.3.1 网关全局过滤器（sky-gateway）

**AuthGlobalFilter.java**

```java
package com.sky.filter;

import com.alibaba.fastjson2.JSON;
import com.sky.constant.JwtClaimsConstant;
import com.sky.properties.JwtProperties;
import com.sky.utils.JwtUtil;
import io.jsonwebtoken.Claims;
import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.cloud.gateway.filter.GatewayFilterChain;
import org.springframework.core.Ordered;
import org.springframework.core.annotation.Order;
import org.springframework.http.HttpStatus;
import org.springframework.http.server.reactive.ServerHttpRequest;
import org.springframework.http.server.reactive.ServerHttpResponse;
import org.springframework.stereotype.Component;
import org.springframework.util.AntPathMatcher;
import org.springframework.web.server.ServerWebExchange;
import reactor.core.publisher.Mono;

@Slf4j
@Component
@Order(1)
public class AuthGlobalFilter implements Ordered, GatewayFilter {

    @Autowired
    private JwtProperties jwtProperties;

    private static final AntPathMatcher PATH_MATCHER = new AntPathMatcher();

    @Override
    public Mono&lt;Void&gt; filter(ServerWebExchange exchange, GatewayFilterChain chain) {
        ServerHttpRequest request = exchange.getRequest();
        String path = request.getURI().getPath();

        // 判断是否需要登录校验（排除公开接口）
        if (isPublicPath(path)) {
            return chain.filter(exchange);
        }

        // 获取Token
        String token = null;
        if (path.startsWith("/admin/")) {
            token = request.getHeader(jwtProperties.getAdminTokenName());
        } else {
            token = request.getHeader(jwtProperties.getUserTokenName());
        }

        try {
            log.info("网关校验token: {}", token);
            Claims claims = JwtUtil.parseJWT(jwtProperties.getUserSecretKey(), token);
            Long userId = Long.valueOf(claims.get(JwtClaimsConstant.USER_ID).toString());
            log.info("当前用户id：{}", userId);

            // 将用户ID存入请求头，转发到下游微服务
            ServerWebExchange newExchange = exchange.mutate()
                    .request(builder -> {
                        builder.header("userId", userId.toString());
                        return builder.build();
                    })
                    .build();

            return chain.filter(newExchange);
        } catch (Exception ex) {
            ServerHttpResponse response = exchange.getResponse();
            response.setStatusCode(HttpStatus.UNAUTHORIZED);
            String errorJson = JSON.toJSONString(com.sky.result.Result.error("NOT_LOGIN"));
            return response.writeWith(Mono.just(response.bufferFactory().wrap(errorJson.getBytes())));
        }
    }

    /**
     * 判断是否为公开接口（无需登录）
     */
    private boolean isPublicPath(String path) {
        String[] publicPaths = {
                "/admin/employee/login",
                "/user/user/login",
                "/user/user/wxLogin",
                "/user/shop/status"
        };
        for (String pattern : publicPaths) {
            if (PATH_MATCHER.match(pattern, path)) {
                return true;
            }
        }
        return false;
    }

    @Override
    public int getOrder() {
        return 0;
    }
}
```

**UserInterceptor.java**

```java
package com.sky.interceptor;

import com.sky.context.BaseContext;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Component;
import org.springframework.web.servlet.HandlerInterceptor;
import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;

@Slf4j
@Component
public class UserInterceptor implements HandlerInterceptor {

    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) throws Exception {
        // 从请求头获取用户信息（由网关过滤器设置）
        String userId = request.getHeader("userId");
        
        if (userId != null && !userId.isEmpty()) {
            log.info("拦截器获取到用户ID：{}", userId);
            BaseContext.setCurrentId(Long.valueOf(userId));
        }
        
        return true;
    }

    @Override
    public void afterCompletion(HttpServletRequest request, HttpServletResponse response, Object handler, Exception ex) throws Exception {
        // 请求结束后清除ThreadLocal，防止内存泄漏
        BaseContext.removeCurrentId();
    }
}
```

```java
package com.sky.api.config;

import com.sky.context.BaseContext;

import feign.RequestTemplate;

import org.springframework.stereotype.Component;

        }
    }
}
```

### 7.4 业务服务本地配置文件

每个业务服务只需要保留一个精简的 `application.yml` 或 `bootstrap.yml`，用于指定从Nacos加载哪些配置：

#### 7.4.1 添加依赖（各服务pom.xml）

```xml
&lt;!-- Nacos配置中心 --&gt;
&lt;dependency&gt;
    &lt;groupId&gt;com.alibaba.cloud&lt;/groupId&gt;
    &lt;artifactId&gt;spring-cloud-starter-alibaba-nacos-config&lt;/artifactId&gt;
&lt;/dependency&gt;
&lt;!-- 支持配置动态刷新 --&gt;
&lt;dependency&gt;
    &lt;groupId&gt;org.springframework.boot&lt;/groupId&gt;
    &lt;artifactId&gt;spring-boot-starter-actuator&lt;/artifactId&gt;
&lt;/dependency&gt;
```

#### 7.4.2 创建 bootstrap.yml（以sky-product-service为例）

在 `src/main/resources/` 下创建 `bootstrap.yml`（优先级高于application.yml）：

```yaml
spring:
  application:
    name: sky-product-service  # 必须与Nacos中Data ID对应
  cloud:
    nacos:
      discovery:
        server-addr: localhost:8848
        enabled: true
      config:
        server-addr: localhost:8848
        file-extension: yaml
        shared-configs:  # 引入公共配置
          - data-id: sky-common.yaml
            group: DEFAULT_GROUP
            refresh: true  # 支持动态刷新
```

**其他服务只需修改 `spring.application.name` 为对应的服务名即可**

### 7.6 配置刷新机制

#### 7.6.1 @RefreshScope 动态刷新

在需要动态刷新配置的类上添加注解：

```java
import org.springframework.cloud.context.config.annotation.RefreshScope;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;

@RefreshScope  // 支持配置动态刷新
@Component
public class ShopStatusConfig {

    @Value("${shop.status:1}")
    private Integer status;

    public Integer getStatus() {
        return status;
    }

    // getter/setter...
}
```

#### 7.6.2 @ConfigurationProperties 绑定配置

```java
import org.springframework.boot.context.properties.ConfigurationProperties;
import org.springframework.cloud.context.config.annotation.RefreshScope;
import lombok.Data;

@Data
@RefreshScope
@ConfigurationProperties(prefix = "sky.jwt")

    private Long adminTtl;
    private String adminTokenName;
    
    private String userSecretKey;
    private Long userTtl;
    private String userTokenName;

```

### 7.7 配置管理最佳实践

| 配置类型 | 存储位置 | 说明 |
|---------|---------|-----|
| **公共配置** | Nacos: sky-common.yaml | JWT、Redis、OSS等所有服务共用 |
| **服务独立配置** | Nacos: {service-name}.yaml | 数据库连接、端口等各服务特有配置 |
| **敏感信息** | 环境变量或本地配置 | 密码、密钥等不建议提交到Nacos |
| **本地开发覆盖** | 本地 bootstrap-local.yml | 开发环境特殊配置 |

### 7.8 Nacos控制台操作步骤

1. **登录控制台**：http://localhost:8848/nacos
2. **创建配置**：配置管理 → 配置列表 → + 号
3. **填写信息**：
   - Data ID: `sky-common.yaml`
   - Group: `DEFAULT_GROUP`
   - 配置格式: `YAML`
   - 配置内容: 粘贴上面的YAML内容
4. **发布配置**：点击发布按钮
5. **验证生效**：查看微服务启动日志是否成功拉取配置

### 7.9 配置优先级说明

Spring Cloud Alibaba Nacos配置优先级（从高到低）：

1. **本地 bootstrap-{profile}.yml**
2. **Nacos共享配置 (shared-configs)**
3. **Nacos主配置 ({application-name}.yaml)**
4. **本地 application.yml**
5. **默认配置**

**建议**：将大部分配置放在Nacos，本地只保留Nacos连接地址和紧急回退配置。

## 九、注意事项

### 9.1 前端代码无需修改
- 网关端口保持8080，与原单体一致
- 路由路径保持不变，网关负责转发

### 9.2 分布式事务
- 下单操作涉及订单、库存（如果有），建议使用Seata保证一致性
- 本项目中商品没有库存字段，暂时可以不用Seata

### 9.3 报表统计
- 报表统计功能合并到订单服务中
- 订单服务通过Feign调用商品服务、用户服务获取统计数据

### 9.4 JWT鉴权
- 网关可以做统一鉴权，也可以各服务自己鉴权
- 建议各服务自己鉴权，网关只做路由

### 9.5 服务降级说明
- 每个API模块都有对应的fallback包
- 当服务调用失败时，自动进入降级逻辑
- 可以在Sentinel控制台动态配置流控和熔断规则
- 降级逻辑可以返回友好提示或默认数据，避免系统雪崩

### 9.6 测试
- 改造过程中建议逐个服务测试
- 先测试单个服务的内部功能，再测试服务间调用
- 测试服务降级功能，模拟服务不可用场景

## 十、总结

本方案将单体应用拆分为**5个微服务**（网关+4个业务服务），通过Gateway网关统一入口，保持前端代码不变。核心步骤：

1. 创建公共API模块定义Feign接口及降级实现
2. 创建网关服务路由请求
3. 按业务领域拆分服务和数据库
4. 报表功能合并到订单服务
5. 服务间通过OpenFeign调用，集成Sentinel熔断降级
6. 使用Nacos做服务注册发现

改造完成后，系统具有更好的可扩展性、可维护性和容错能力。
